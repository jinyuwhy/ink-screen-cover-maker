# 墨水屏封面屏保

一个轻量 Windows 桌面工具：查找或粘贴图书封面，将其转换为适合墨水屏设备的灰度 PNG 屏保。

## 功能

- 通过 Open Library 进行用户主动、低频的封面搜索
- 从浏览器或图片软件复制并粘贴封面
- 使用本地 JPG、PNG、WebP、BMP 或 TIFF 图片
- 完整封面留白或铺满屏幕裁切
- 256 级灰度、16 级灰度、黑白抖动
- 对比度调整与轻微锐化
- 常见墨水屏设备分辨率预设
- 自定义宽高及横竖屏交换
- 导出灰度 PNG，文件名包含实际分辨率

## 使用

1. 安装 Python 3.10 或更高版本。
2. 双击 `启动工具.bat`。首次运行会安装 Pillow。
3. 输入书名并点击“搜索封面”，或使用“网页查找”“粘贴封面”“本地图片”。
4. 选择设备预设或填写自定义分辨率。
5. 调整效果并生成 PNG。

搜索结果来自 Open Library。双击结果可打开相应的 Open Library 页面。若搜索不到中文新书，点击“网页查找”，在浏览器中复制封面图片，再回到工具点击“粘贴封面”。应用不会自动读取或抓取该网页。

## 常见分辨率预设

| 类型或代表设备 | 竖屏分辨率 |
| --- | ---: |
| BOOX Palma 等手机型墨水屏 | 824 × 1648 |
| 6 英寸 300PPI 阅读器 | 1072 × 1448 |
| Kindle Paperwhite 11 | 1236 × 1648 |
| 汉王 Clear 7 Turbo+、常见 7 英寸 300PPI 阅读器 | 1264 × 1680 |
| Supernote Nomad、reMarkable 2、部分 10.3 英寸设备 | 1404 × 1872 |
| 8 英寸 300PPI 阅读器 | 1440 × 1920 |
| 10.2/10.3 英寸 300PPI 设备 | 1860 × 2480 |
| Supernote Manta | 1920 × 2560 |
| 13.3 英寸 300PPI 设备 | 2400 × 3200 |

不同代际的同名设备可能使用不同面板，请以设备官方规格为准。
